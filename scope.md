# Assessment Scope

## Overview

This document defines the scope of the authorized web application security assessment conducted against Kriva.

The assessment was performed with written authorization from the system owner before testing began.

## In-Scope Assets

The authorized assessment covered the following domains:

- `kriva.no`
- `www.kriva.no`
- `auth.kriva.no`

## Assessment Areas

Within the agreed scope, the assessment covered:

- Passive reconnaissance
- Subdomain and technology identification
- HTTP and security header analysis
- DNS and domain information
- Web application behaviour
- API communication and endpoints
- Authentication controls
- Authorization and access control
- Input validation
- Security configuration
- Risk assessment

## Test Accounts

Two dedicated test accounts were created and used during the assessment to evaluate access control between users.

Testing of user-to-user access was performed using these controlled test accounts.

## Authorization

Written authorization was obtained from the system owner before the security assessment was conducted.

All testing was performed within the agreed scope and for defensive security assessment purposes.

## Scope Limitations

Testing was limited to the agreed domains and application functionality.

No unauthorized systems, users, or third-party infrastructure were intentionally targeted.

The assessment was conducted as a controlled security test and does not represent unrestricted penetration testing of the underlying infrastructure.

## Assessment Approach

The assessment followed a structured six-phase process:

1. Reconnaissance
2. API Mapping and Analysis
3. Authentication Testing
4. Authorization Testing
5. Input Validation
6. Security Configuration

Findings were documented together with their observed impact, risk assessment, and recommended remediation.
